# KiCad: Power Supply and RGB LED Blocks

Report: [KiCad TPS and RGB LED Report](docs/KiCad_TPS_and_RGB_LED_Report.pdf), 10 pages.

## Contents

- **TPS55288 buck-boost power block.** Reproduction of an existing schematic with components imported from LCSC through EasyEDA, all passives in 0603 footprints. The block converts a 5 to 14 V input to 5 V.
- **RGB LED control block (task TEAM-797).** LED driver with I2C connector, RGB LEDs with series resistors, and a USB Type-C input.
- **Git workflow.** Fork of the source repository, a feature branch for each task, and a pull request for each block.

Only the report is published here. The KiCad schematic files are not included.
